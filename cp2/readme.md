## Instruções
Bom dia turma!

Para nosso segundo CheckPoint, vocês devem construir um aplicativo utilizando HTML/CSS/Javascript que mostre e filtre atores e atrizes. O aplicativo web deve utilizar o array de objetos JSON no arquivo dados.js em anexo (o arquivo está comprimido).

### O aplicativo deve conter:
* Título
* Renderização de todos os atores e atrizes do array em um grid de cards contendo os dados (foto, nome, país e data de nascimento)
* Um campo de busca utilizando input (type="text") que filtre os cards pelo nome conforme o usuário digita, usando oninput, filter() e includes(), conforme visto nas aulas.

Dois snapshots da tela de seu projeto:
* Um snapshot da tela ao abrir
* Um snapshot da tela com filtro aplicado
